# Ross Momentum Strategy Contract

Issue: #1052
Base audited: `26a02fe` (`main`, PR1050 merge)
Purpose: concise canonical authority/index for Ross Momentum rules already implemented and certified. This document is an index, not a new strategy specification.

## Authority Rules

- Production policy and runtime code are the highest authority.
- Certification reports and governance tests document what has been verified.
- Ross reference documents explain intent, but they do not override production policy, gates, or tests.
- No production behavior, thresholds, session formulas, catalyst semantics, float behavior, broker authority, PAPER authority, or LIVE authority is changed by this contract.

## Five Pillars

The canonical Ross stock-selection pillars are:

1. Price
2. Gap / percentage move
3. Float
4. Volume
5. News / catalyst

Supporting implementation metrics are not extra pillars: RVOL, spread/liquidity, session normalization, data quality, ranking weights, halt/SSR state, patterns, and technical structure.

## Issue #1051 Classification

The #1052 index classifies the likely #1051 root cause as:

- Primary: existing news engine not invoked in READ_ONLY.
- Secondary: preparation cache not reused as accepted runtime catalyst authority.
- Also relevant: provider/config disabled by mode gate when `allow_news` is false for READ_ONLY/PAPER/LIVE.

This is not a threshold issue, not a catalyst-bypass issue, and not evidence that `DATA_UNAVAILABLE` should be promoted to confirmed catalyst. #1051 must repair wiring against this contract, after this contract is reviewed.

## Drift Risks To Preserve For Follow-Up

- READ_ONLY scanner currently skips fast news enrichment, so real catalyst proof fails closed as `DATA_UNAVAILABLE`.
- Prep news can be fetched by the prep engine, but the canonical prep artifact does not currently preserve news/catalyst fields.
- Focus-empty diagnostics must preserve Focus-stage `DROP_NO_CATALYST`; unrelated earlier-universe `DROP_FLOAT_UNKNOWN` counts must not obscure that diagnosis.
- Trade-management code contains enforced partial/trailing/breakeven behavior, but Ross certification remains partial and must not be overclaimed.
