# ibkr-trading-system

## Overview
ibkr-trading-system is a modular, deterministic trading operating system
designed to automate intraday trading strategies safely and explainably.

The first reference implementation is **Ross Cameron’s Momentum Strategy**.
The architecture is strategy-agnostic and supports future expansion.

## What This System Is
- A research‑grade trading OS
- A live‑capable system with strict risk controls
- A learning and recovery‑capable platform

## What This System Is Not
- Not a black‑box trading bot
- Not a high‑frequency system
- Not an experimental playground
