# Mean Reversion Strategy — Immutable Contract

A trade is valid only if ALL clauses hold, in this order:

1) Abnormal extension (distance from mean is statistically meaningful)
2) Continuation failure (evidence momentum has stopped working)
3) Clear mean (a defensible equilibrium reference exists)
4) Confirmed entry (structure-based, post-exhaustion)
5) Hard invalidation (structural stop; never widened)
6) Defined target (mean-based target(s) defined before entry)
7) Regime approval (stand down on trend/news/macro regimes)
8) Positive asymmetry (RR ≥ minimum)

If any clause fails → NO TRADE.
