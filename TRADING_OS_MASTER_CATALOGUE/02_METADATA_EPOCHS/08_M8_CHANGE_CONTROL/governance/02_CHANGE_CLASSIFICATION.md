# CHANGE CLASSIFICATION

All changes MUST be classified into one of the following:

CLASS A — NON-BREAKING
- Additive changes
- No impact on existing certifications

CLASS B — BEHAVIOR-AFFECTING
- Changes strategy behavior or defaults
- Requires scoped re-certification

CLASS C — BREAKING / CONSTITUTIONAL
- Modifies Core or Metadata Epoch law
- Requires governance revision and re-certification

END
