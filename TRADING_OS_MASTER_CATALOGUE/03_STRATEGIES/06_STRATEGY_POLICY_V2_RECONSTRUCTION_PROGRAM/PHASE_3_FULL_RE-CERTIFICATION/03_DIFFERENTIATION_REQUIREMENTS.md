# DIFFERENTIATION REQUIREMENTS

A strategy must not:

- Use identical setup-family lists as unrelated strategy types.
- Use identical trigger sets across unrelated domains.
- Rely solely on template risk/exit definitions.

A strategy must:

- Declare domain-specific setup taxonomy.
- Declare domain-specific exit logic.
- Declare explicit intrabar doctrine (APPLICABLE / NOT_APPLICABLE).
- Declare safety escalation model.
