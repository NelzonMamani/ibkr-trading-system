# 02_EPOCH_PROCESS_TEMPLATE

Each epoch must follow this exact process.

Steps:
1. Read epoch intent.
2. Inspect actual implementation.
3. Identify authoritative components.
4. Identify gaps or duplication.
5. Apply amendments if beneficial.
6. Re-run verification commands.
7. Produce audit report.
8. Append constitution and system state.

Mandatory audit sections:
- Intended Capability
- Observed Implementation
- Gaps / Risks
- Amendments Applied
- Verification Evidence
- Certification Statement
