# E16_NO_TRADE_CONTEXTS — OVERVIEW

E16 defines situations where the Trading OS must explicitly refuse to trade.

Purpose:
- Prevent structurally bad trades
- Encode trader discretion as system law
- Eliminate emotional or ambiguous execution
- Protect capital during adverse conditions

This epoch formalises WHEN the correct action is:
DO NOTHING.

This epoch does NOT:
- Modify strategies
- Change signal logic
- Override valid trade setups

No-trade contexts override all strategies.

END
