# E16_NO_TRADE_CONTEXTS — TAXONOMY

No-trade contexts are classified as:

1. Market Structure Contexts
   - Extreme market chop
   - Absence of follow-through
   - Broad market breakdown

2. Session Contexts
   - Market CLOSED
   - Illiquid transition windows
   - Post-halt instability

3. Data Integrity Contexts
   - Missing critical data
   - Session misalignment
   - Stale reference prices

4. Risk Contexts
   - Daily max loss hit
   - Volatility shock
   - Correlated drawdown

5. Behavioural Contexts
   - Consecutive losses
   - Strategy confidence collapse
   - Rule violations detected

Invariant:
If context classification is uncertain, default is NO TRADE.

END
