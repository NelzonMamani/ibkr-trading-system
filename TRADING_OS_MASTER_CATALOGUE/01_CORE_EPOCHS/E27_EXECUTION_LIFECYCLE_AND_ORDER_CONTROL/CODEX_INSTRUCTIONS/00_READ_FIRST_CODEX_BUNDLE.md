# 00_READ_FIRST — E27 Code Bundle

This bundle contains the implementation instructions for E27.

## Intent
These files are written for Codex to execute directly from the repository after the governance files are placed in their proper project locations.

## Use
1. Place the governance bundle into the appropriate governance/catalogue area.
2. Place this bundle into the appropriate Codex instruction area.
3. Then use a final master instruction block to tell Codex to read these files and implement E27.
