# E18 — CANDLESTICK FOUNDATION MODEL (3-LAYER + CHECKLIST LAW)

Candlesticks are foundation primitives that support setups, triggers, conditions, and confirmations.
Candlesticks are NOT strategy policy.

E18 requires THREE layers:

LAYER 1 — Named patterns (human-recognisable)
- Single-candle named patterns
- Multi-candle named patterns

LAYER 2 — Functional behaviours (parameterised mechanics)
- Range expansion / contraction, wick rejection strength, CLV, etc.

LAYER 3 — Contextual candle states (candle ↔ level/indicator interaction)
- reclaim/reject/hold vs VWAP/EMA/key levels/HOD/LOD/opening range

INVARIANT:
Setups may use candlesticks, but are not defined by candlesticks alone.

END
