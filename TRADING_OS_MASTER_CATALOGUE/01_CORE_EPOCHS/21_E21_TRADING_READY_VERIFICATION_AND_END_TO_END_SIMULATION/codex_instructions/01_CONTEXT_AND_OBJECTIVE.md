# 01_CONTEXT_AND_OBJECTIVE

Objective:
Codex must bring the Trading OS to a **provably trading-ready state**.

This means:
- Not architectural completeness
- Not policy elegance
- But **verified, end-to-end correctness**

The result must answer, with evidence:
"Can this system trade LIVE safely, under strict caps, without undefined behavior?"

Codex must assume:
- No component is trusted without proof
- Placeholders are FAILURES
- Silence is not success
